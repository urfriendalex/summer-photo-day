# Summer Photo Day

Outdoor park photo-day landing page and lead capture form, adapted from the Blooming Diva template for a summer picnic experience in Warsaw.

## Development

```bash
npm install
npm run dev
```

## Environment

Copy `.env.example` to `.env.local` and provide:

- `RESEND_API_KEY`
- `BOOKING_EMAIL_TO`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
